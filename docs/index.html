    使い方・抽出条件

    両軸が線形目盛の画像を対象とする。軸の最小点・最大点は文字ではなく目盛の位置を指定する。画像はホイールまたは＋／−で拡大・縮小できる。拡大後はスクロールで移動する。

    自動検出は白背景の線を対象とする。候補は元画像と照合してから保存する。同色の交差線、文字や誤差棒が接触する線は混ざる場合がある。途切れた区間には点を生成しないが、再描画では取得点を直線で結ぶ。欠損区間の測定値を復元したことにはならない。

    CSVはx,y列、UTF-8 BOM付きで保存する。行順を保持し、CSVに単位や校正情報は含めない。CSV描画での点表示は初期状態でOFFである。再読み込みやタブを閉じる前にCSVを保存する。
