平滑化は画像の画素による段差を抑える近似処理。幅を広げると鋭いピークや折れ曲がりも変化するため、元画像と比較する。設定変更後は再抽出する。読込済みのCSVには適用しない。

画像上の縦線2本（x最小・x最大）と横線2本（y最小・y最大）をドラッグして、対応する目盛に合わせる。線の交点を基準座標に使用する。矢印キーで1 px、Shift＋矢印で10 px移動できる。点を取得するときは「画像の操作」を切り替える。

px：元画像の画素の位置・距離。%：元の試料長に対する変形量の百分率。MPa：応力、1 MPa = 10⁶ N/m²。

    使い方・抽出条件

    両軸が線形目盛の画像を対象とする。4本の校正線は文字ではなく、対応する目盛の位置に合わせる。x最小線とy最小線の交点が最小値の基準、x最大線とy最小線の交点がx最大、x最小線とy最大線の交点がy最大の基準になる。画像はホイールまたは＋／−で拡大・縮小できる。拡大後はスクロールで移動する。

    自動検出は白背景の線を対象とする。候補は元画像と照合してから保存する。同色の交差線、文字や誤差棒が接触する線は混ざる場合がある。途切れた区間には点を生成しないが、再描画では取得点を直線で結ぶ。欠損区間の測定値を復元したことにはならない。

    CSVはx,y列、UTF-8 BOM付きで保存する。行順を保持し、CSVに単位や校正情報は含めない。CSV描画での点表示は初期状態でOFFである。再読み込みやタブを閉じる前にCSVを保存する。
