# graph-digitizer-web

論文中のグラフ画像から曲線を手動または自動で取得し、軸の目盛に基づいて数値データに変換してCSVに保存するWebツールである。複数CSVを色分けして同じ図に描画し、曲線を比較できる。

デスクトップ版は別リポジトリ [graph-digitizer](https://github.com/Yagi-031382/graph-digitizer) で維持する。Web版はHTML・CSS・JavaScriptで動作し、Pythonやサーバー上の画像処理を必要としない。入力画像とCSVはブラウザー内で処理し、サーバーへ送信しない。外部CDNのスクリプトも読み込まない。

## GitHub Pagesでの公開

1. リポジトリのSettingsを開く。
2. 左側のPagesを開く。
3. Build and deploymentのSourceを「Deploy from a branch」にする。
4. Branchを「main」にする。
5. フォルダーを「/docs」にする。
6. Saveを押す。

公開先の予定URLは `https://Yagi-031382.github.io/graph-digitizer-web/` である。GitHub Pagesの処理が完了するまではアクセスできない。公開後はmainのdocs以下を更新すると再配信する。

## ローカルでの起動

リポジトリ内で、Pythonがある場合は以下を実行する。8000はHTTPサーバーのポート番号（無次元の識別番号）である。

```powershell
python -m http.server 8000 --directory docs
```

次にブラウザーで `http://localhost:8000/` を開く。HTMLファイルをfile://で直接開く方式は、JavaScriptモジュールとWorkerの制限のため未対応である。配信時のビルドやnpm installは不要である。

## CSV取得モード

1. 「画像を開く」を押す。
2. PNGまたはJPEG画像を選択する。
3. x最小の軸値を入力する。
4. x最大の軸値を入力する。
5. y最小の軸値を入力する。
6. y最大の軸値を入力する。
7. 青い縦線「x最小」を対応するx軸最小の目盛にドラッグする。
8. 青い縦線「x最大」を対応するx軸最大の目盛にドラッグする。
9. 茶色の横線「y最小」を対応するy軸最小の目盛にドラッグする。
10. 茶色の横線「y最大」を対応するy軸最大の目盛にドラッグする。
11. 手動では「画像の操作」を「曲線のデータ点を取得」に切り替え、曲線上の点を1点ずつクリックする。自動では「曲線を自動検出」を押す。
12. 画像と再描画を照合する。
13. 「CSV保存」を押す。

画像読込時に4本の校正線を画像の内側10 %・90 %の位置に配置する。これは仮の位置なので、使用前に必ず実際の目盛へ合わせる。「画像の操作」が「校正線を移動」のときは、線またはラベルをドラッグして調整できる。線にキーボードのフォーカスを合わせると、縦線は左右矢印、横線は上下矢印で元画像の1 px、Shift併用で10 px移動する。線は画像の外へ移動しない。同じ向きの2本を重ねると校正エラーになり、離すと再計算する。

基準座標は、x最小線とy最小線の交点をx最小・y最小、x最大線とy最小線の交点をx最大、x最小線とy最大線の交点をy最大として求める。右上の交点はx最大・y最大に対応する。座標は各軸値の下に元画像のpx単位で表示する。拡大・縮小しても元画像座標を保持する。校正線を動かすと取得済みの点は元画像座標から再計算し、検出候補は破棄する。校正線は表示用の重ね合わせであり、自動抽出の入力画像には含めない。「曲線のデータ点を取得」の間は線のドラッグを無効にし、線の上でも点を取得できる。

自動検出は水平範囲が最長の候補を選ぶ。他の候補は検出候補欄から選び、「選択候補を取得点に反映」で切り替える。既存点の置き換えは確認する。元画像の境界から3 pxは軸線を避けるため抽出対象から除外する。pxは元画像の画素の位置・距離を表す単位である。

画像はホイール、＋／−ボタンで拡大・縮小し、スクロールバーで移動する。倍率を変更しても元画像の座標を取得する。全体表示で画像を収める。倍率の%は元画像の表示寸法に対する百分率である。

取得点の表で行を選ぶと、右側の再描画の対応点がオレンジ色になる。矢印キーで行を移動でき、Escapeで選択を解除する。選択点の削除、最後の点を戻す操作にも対応する。軸値を変えると、保持する画像座標から取得済みの点を再計算する。軸の校正を変更すると検出候補を破棄する。

CSVはx,y列で、UTF-8 BOM付きでダウンロードする。保存先はブラウザーの設定に従う。単位と校正情報はCSVに含めない。画像の変更とページを離れる際は未保存点を確認する。再読み込みで取得点と読込CSVは失われるため、事前にCSVを保存する必要がある。

## CSV描画モード

「CSV描画」タブで「CSVを追加（複数選択可）」からCSVを読み込む。CSVごとに色を変え、拡張子を含むファイル名を凡例に表示する。「点を表示」は初期状態でOFFであり、ONにすると線と点、OFFにすると線だけになる。「除外」で曲線を図から除き、元ファイルは変更しない。

CSVはx,y列、UTF-8またはUTF-8 BOM付き、有限の数値が必要である。空欄・NaN・無限大を含むCSVや列名がないCSVは拒否する。有効な他のファイルは読み込める。同じファイル名のCSVを再読込すると更新する。ブラウザーでは元ファイルのフルパスを取得しないため、別フォルダーに同名のCSVがある場合は先にファイル名を変える必要がある。

CSV描画の「x軸の表示範囲」「y軸の表示範囲」は、それぞれ「自動」（既定）または「指定」を選べる。自動は読み込んだ曲線全体から従来どおり余白付きの範囲を決める。最小値・最大値は自動の状態でもキーボードで入力でき、入力するとその軸が「指定」に切り替わって即座に再描画する。「自動」を選び直すと曲線全体の自動範囲に戻る。範囲外の線と点はグラフの表示枠で切り取り、枠を横切る線は枠内の部分だけ表示する。元CSV、読み込んだ数値、点の順序は変更しない。

各軸の「最小値を0にする」は既定でOFF。ONでは表示最小値を0に固定し、最小値欄を0表示にして無効にする。OFFに戻すと、ONにする前の入力値（空欄を含む）を復元して使用する。自動範囲でも0固定を利用できる。自動では最大値を曲線から決める。入力欄には指定範囲の入力値を保持し、自動で決めた範囲はグラフの目盛で確認する。0固定中の最小値欄以外はいつでも入力できる。

指定範囲の有効な最小値・最大値が空欄または有限値でない場合、最大値が最小値以下の場合は、軸ごとのエラーを表示して比較グラフを消去する。修正すると再描画する。0固定中は保持した最小値欄を検証せず、0と最大値を比較する。自動範囲で0固定した際も、自動最大値が0以下ならエラーになる。表示幅が数値計算の範囲を超える指定も拒否する。

既定のx軸名・単位はひずみ `Strain [%]`、y軸は応力 `Stress [MPa]`。%は元の試料長に対する変形量の百分率、MPaは応力の単位で、`1 MPa = 10^6 N/m²`。軸名・単位を変更すると、その入力を軸に表示する。範囲の入力値もその軸の単位で指定し、数値の単位換算は行わない。

両モードは独立した軸名・単位を保持する。切り替えてもデータは保持する。単位の換算は行わない。比較前に各CSVで単位とひずみ・応力の定義をそろえる必要がある。

## 単位・座標変換

- xの既定値はひずみ [%]。%は元の試料長に対する変形量の百分率であり、`100 × (変形後の長さ − 元の長さ) / 元の長さ`である。
- yの既定値は応力 [MPa]。MPaは応力の単位で、`1 MPa = 10^6 N/m²`である。Nは力、m²は面積の単位である。
- `(u,v)` [px]は元画像の座標であり、左上が原点、uは右向き、vは下向きに増加する。

入力は元画像の座標 [px]、軸の基準点 [px]、対応する軸値である。出力は指定した軸単位の(x,y)である。変換式はデスクトップ版と共通である。

```text
x = x_min + (u − u_x_min) / (u_x_max − u_x_min) × (x_max − x_min)
y = y_min + (v − v_y_min) / (v_y_max − v_y_min) × (y_max − y_min)
```

## 自動検出の処理と制限

白背景、x軸が水平、y軸が垂直、両軸が線形目盛である画像を対象とする。黒・灰色をOtsu閾値で分離し、色の付いた線をHSVの色相と彩度で分離する。Web版ではこの処理をJavaScriptで実装し、Web Workerで実行する。OpenCV.jsのダウンロードは不要である。

黒・灰色の水平・垂直線が抽出範囲の幅または高さの80 %以上を直線で占める場合はグリッド候補として除去する。80 %は抽出範囲の幅または高さに対する比率である。「途切れの接続距離」の既定値は12 px、範囲は0～100 pxであり、正方形カーネルの幅は設定値＋1 pxである。0 pxでは膨張処理を行わない。膨張結果の8近傍の接続で近接する破線をまとめるが、点の座標は膨張前の線から取得する。各画像列の線の垂直座標の中央値を採用し、列ごとに1点を取得する。

デスクトップ版はOpenCVの楕円カーネル、Web版は正方形カーネルを使用する。また、画像の色変換と画像のデコードはブラウザーによって差が生じ得るため、抽出結果の完全一致は保証しない。Web版でも元画像との照合が必要である。

線が存在しない画像列には点を生成しない。ただし再描画ではCSVの行順に直線で結ぶため、途切れの両端も線で結ばれる。欠損区間の測定値を復元したことにはならない。自動検出した点はx値の昇順であり、手動点と読込CSVの行順は変更しない。

同色の交差線、文字・誤差棒が接触する曲線、白以外の背景、軸線やグリッドに重なる曲線、同じx値に複数のy値を持つ曲線は誤検出や欠落があり得る。端点が軸の境界に重なる場合も除外され得る。水平範囲が最長の候補が目的の曲線とは限らない。処理時間と扱える画像サイズは利用端末のメモリーとブラウザーに依存し、デスクトップ版との差は未計測である。

## 検証

Node.jsがある環境で、以下を実行する。単体検証に外部パッケージは不要である。

```powershell
npm test
```

HTTP配信したWeb版はChromiumで、画像読込、4本の校正線のドラッグ・交点・キーボード調整、手動取得、拡大後の座標変換、選択点のオレンジ表示、CSVダウンロード、自動抽出、複数CSV比較、点表示切替、読込エラー、狭い画面での表示を検証する。実際の文献画像の抽出精度は画像ごとに確認する必要がある。

ブラウザーの自動検証はPlaywrightとChromiumがある環境で `npm run test:browser` を実行する。システムのChromiumを使う場合は `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium` を指定する。表示範囲の自動・指定切替、各軸の0固定と入力値復元、無効範囲、枠外の線・点の切り取り、軸名変更も検証する。
